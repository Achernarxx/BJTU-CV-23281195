# 图像检索 —— 使用说明文档

## 一、环境准备

### 1. 安装依赖

在项目根目录下执行以下命令安装所需依赖：


pip install -r requirements.txt

### 2. 目录结构

项目目录结构如下：

```
CV_Homework/image_retrieval/
├── base/                     # 图像库（共 7728 张图片）
│   ├── BJTU/                 # 12 个地标图片（共 5063 张）
│   └── util_pic/             # 辅助图片（共 2665 张）
│
├── query/                    # 查询图像（共 135 张）
├── index/                    # 特征索引目录（运行后自动生成）
│   ├── image_paths.pkl       # 图像路径列表
│   └── features.npy          # 提取的图像特征矩阵
│
└── results/                  # 结果输出目录（运行后自动生成）
    ├── P@K_charts/           # 每个地标的 P@K 柱状图（12 张 PNG）
    └── retrieval/            # 检索结果可视化图像
```

## 二、运行步骤

### 1. 启动 Jupyter Notebook

在终端中进入项目根目录并启动 Jupyter Notebook：

```bash
jupyter notebook
```

### 2. 打开文件

在 Jupyter 界面中，点击打开 `Image Retrieval.ipynb` 文件。

### 3. 顺序执行所有单元格

请按顺序依次执行 Notebook 中的每个单元格，主要流程包括：

- **环境检查和库导入**：检查所需库是否完整。
- **配置路径和统计图片**：设置项目路径并统计图像库和查询集数量。
- **定义特征提取器并构建索引**：提取图像库特征并保存至 `index/` 目录（**首次运行需等待约 20 分钟**）。
- **加载索引并执行检索**：对查询图像进行检索。
- **计算 P@K 评估指标**：输出检索精度。
- **生成 12 个地标的 P@K 柱状图**：保存至 `results/P@K_charts/`。
- **可视化检索结果示例**：展示部分查询图像的检索结果。

## 三、关键配置

在 Notebook 的配置单元格中，可调整以下参数：

```python
PROJECT_ROOT = r"D:/CV_Homework"           # 项目根目录（请根据实际位置修改）
K_VALUES = [20, 40, 60]                    # 评估时使用的 K 值列表
LANDMARK_ABBR = ["fhy", "jx", "kx", ...]   # 12 个地标的英文缩写（完整列表见 Notebook）
```

## 四、输出结果

| 输出内容               | 存储位置                                      |
| ---------------------- | --------------------------------------------- |
| 特征索引文件           | `index/image_paths.pkl` 和 `index/features.npy` |
| P@K 评估结果           | 控制台打印输出                                |
| 各大地标 P@K 柱状图    | `results/P@K_charts/`（共 12 张 PNG 图片）    |
| 检索结果可视化示例     | `results/retrieval/`                          |

## 五、注意事项

1. **首次运行耗时**：构建特征索引需要对 7726 张图片提取特征，预计耗时约 **20 分钟**，请耐心等待。
2. **GPU 支持**：如果系统配有 NVIDIA GPU 且已安装 CUDA，程序将自动使用 GPU 加速；否则自动回退至 CPU。
3. **路径修改**：请根据实际项目存放位置，修改 `PROJECT_ROOT` 变量值。
4. **内存要求**：建议运行环境具有 **8GB 及以上** 内存，以保证特征提取和检索过程流畅。
